# Publicação

Ao concluir uma atualização solicitada para este projeto, valida as alterações, cria um commit com os ficheiros pertinentes e envia-o para `origin` no GitHub, conforme autorizado pelo proprietário. Inclui o link do commit na entrega.

Mantém fora do Git registos de sessões e landmarks, calibração pessoal, ambientes locais e modelos descarregados. Não incluas alterações alheias à tarefa no commit nem sobrescrevas o histórico remoto.
